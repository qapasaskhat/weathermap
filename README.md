## 🚀 Быстрый старт

### 1. Установите зависимости

Убедитесь, что у вас установлены следующие инструменты:

- Node.js (рекомендуется версия LTS)
- npm или yarn
- Expo CLI  

Установить Expo CLI можно командой:  
```bash
npm install -g expo-cli

# Клонируйте репозиторий:  
git clone https://github.com/qapasaskhat/weathermap.git

# Перейдите в директорию проекта:  
cd project-name

# Установите зависимости
npm install
# или
yarn install

# Запустите проект
expo start
# или
npx expo start

```

📱 Запуск на устройствах
Android
1. Установите приложение Expo Go из Google Play.
2. Отсканируйте QR-код из терминала с помощью приложения Expo Go.

iOS
1. Установите приложение Expo Go из App Store.
2. Отсканируйте QR-код из терминала с помощью камеры вашего iPhone.
